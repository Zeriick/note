# Compiler Notes

这个目录目前主要记录 LLVM/编译器优化里常见的分析和传播类概念。可以先按下面顺序看：

1. [[IPSCCP]]：跨过程的稀疏条件常量传播，重点是“常量 + 可达边”的格值分析。
2. [[CVP]]：相关值传播，重点是利用控制流路径上的 predicate/range 信息继续化简。
3. [[SCEV]]：标量演化分析，重点是把循环里的标量变化表示成递推表达式。
4. [[RegMask]]：后端寄存器分配相关的寄存器保留/破坏信息，重点是 call clobber 对分配决策的影响。

## 关系速记

`IPSCCP` 和 `CVP` 都属于“传播信息来简化 IR”的优化，但关注点不同：

- `IPSCCP` 更像是在 SSA 图和调用图上寻找确定的常量、不可达分支和常量返回值。
- `CVP` 更像是在某条控制流路径上利用已经成立的条件，比如 `x < n`，把后面的比较、边界检查或分支化简掉。

`SCEV` 不直接等价于某个变换，它更像是循环优化的基础分析。很多循环优化先问 SCEV：“这个值每次迭代怎么变？循环最多跑几次？这个下标是否线性增长？”

`RegMask` 属于更靠后的机器码阶段。它不关心 IR 里的值是否常量，而是关心某条机器指令，尤其是 call，会保留哪些物理寄存器、破坏哪些物理寄存器，从而影响寄存器分配和 post-RA 之后的物理寄存器活跃性。
